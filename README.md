# Projeto de streaming

Interface inspirada na Netflix, feita com HTML, CSS e JavaScript. Usa o TMDB para consultar filmes e séries e o YouTube para os trailers.

[Ver a página](https://wesleyttiago.github.io/projeto-streaming-estudo/)

## Rodar no computador

Na pasta do projeto, com Python instalado:

```bash
python3 -m http.server 8000
```

Abra http://localhost:8000.

Projeto de estudo, sem vínculo com a Netflix. Usa a API do TMDB, sem endosso ou certificação do TMDB. A lista fica salva no navegador; não há reprodução de filmes completos.
